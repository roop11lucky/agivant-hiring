STREAMLIT CLOUD SECRETS SETUP

Do NOT upload a real secrets.toml file to GitHub.

After deploying the app in Streamlit Community Cloud:

1. Open your app.
2. Go to App settings.
3. Open Secrets.
4. Paste the configuration below.
5. Replace the Google service-account placeholders with the values
   from your downloaded service-account JSON file.

------------------------------------------------------------

[gcp_service_account]
type = "service_account"
project_id = "YOUR_PROJECT_ID"
private_key_id = "YOUR_PRIVATE_KEY_ID"
private_key = """-----BEGIN PRIVATE KEY-----
YOUR_PRIVATE_KEY
-----END PRIVATE KEY-----
"""
client_email = "YOUR_SERVICE_ACCOUNT_EMAIL"
client_id = "YOUR_CLIENT_ID"
auth_uri = "https://accounts.google.com/o/oauth2/auth"
token_uri = "https://oauth2.googleapis.com/token"
auth_provider_x509_cert_url = "https://www.googleapis.com/oauth2/v1/certs"
client_x509_cert_url = "YOUR_CLIENT_CERT_URL"

[google]
spreadsheet_id = "1QreeVlM379CLvLCoDHAZunzp9tIwwPkQ9LrQUK0ukgE"
worksheet_name = "Sheet1"
drive_folder_id = "1Fl0r5cZFPeWL6Fjhz9uLh2vTuzXfaJV9"

[app]
company_website = "https://www.agivant.com"

------------------------------------------------------------

IMPORTANT:
- Share the Google Sheet with the service-account email as Editor.
- Share the resume Drive folder with the same service-account email as Editor.
- Never upload real private keys to GitHub.
